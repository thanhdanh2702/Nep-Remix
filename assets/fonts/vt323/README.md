# VT323

Font pixel/monospace của Peter Hull, bản Regular 400. Tải từ kho Google Fonts ngày 02/10/2026.

- Font gốc: https://github.com/google/fonts/blob/main/ofl/vt323/VT323-Regular.ttf
- Metadata và subset Vietnamese: https://github.com/google/fonts/blob/main/ofl/vt323/METADATA.pb
- Giấy phép: SIL Open Font License 1.1, kèm nguyên văn tại `OFL.txt`.

Giữ nguyên tệp TTF; CSS phục vụ font từ dự án, không gọi Google Fonts lúc chạy. Chỉ dùng trên giao diện sảnh (`.screen-hub`).
