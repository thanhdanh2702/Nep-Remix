# Room navigation

Code-authored SVG assets for the shared cream header. The paired frames use Vietnamese hồi văn corner ornament, with cream/plum and gold/plum states. The settings rosette combines a gear outline with a lotus. These are decorative assets; navigation labels remain live Vietnamese text.

Frame source size: 72 × 72. CSS border-image slices: 22; rendered border: 12px. Corners remain fixed while edges stretch, so buttons fit different labels and viewport sizes.
